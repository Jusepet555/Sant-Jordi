# Sant Jordi web amb àudio per GitHub Pages

- La música comença quan es toca el botó de regar per primera vegada.
- La pàgina està ajustada perquè al mòbil es vegi tot dins la pantalla.
- Envia sempre l'enllaç de GitHub Pages per WhatsApp.

## Passos
1. Crea un repositori nou a GitHub.
2. Puja-hi `index.html`.
3. Ves a Settings -> Pages.
4. Tria `Deploy from a branch`.
5. Selecciona `main` i `/(root)`.
6. Guarda i espera 1 o 2 minuts.
